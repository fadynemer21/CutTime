## Full description

CuTime makes barber appointments simple for customers and practical for barber
shops.

Customers can discover complete barber profiles, compare services and hours,
check real availability, and reserve a time through a clear review step. The
appointment area keeps upcoming, completed, cancelled, and rescheduled visits
organized in one place.

Barbers can create a public shop, manage services and working hours, block
holiday dates, follow the daily schedule, view customer details, and update
appointment status. Gallery images and verified post-appointment reviews help
customers choose with confidence.

Key features:

- Secure Customer and Barber accounts
- Persistent sessions and password reset
- Searchable real barber catalog
- Services, prices, working hours, and holiday availability
- Availability-based booking with overlap protection
- Appointment cancellation and rescheduling
- Barber Dashboard and customer details
- Ratings only after completed appointments
- Barber gallery support
- In-app appointment updates
- Two-hour and 30-minute appointment reminders
- Customer Mode for Barber accounts

CuTime does not request location, contacts, camera, microphone, or broad photo
library access. Notification permission is optional.
